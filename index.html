AWS Architecture — VPC Practice Build

fig. 01 — vpc-practice-01 · ap-south-1 PRACTICE BUILD

Route Tables configured to send public-subnet traffic through the IGW, keeping the private subnet isolated.
Security Groups scoped per subnet — a web-facing group for the public EC2 instance, a tighter app group for the private one.
